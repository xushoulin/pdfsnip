Extract vs Split vs Delete

Three operations, three different outputs. Here's how to pick the right one.

Most confusion around PDF page tools comes from these three words being used interchangeably. They are not the same operation, and choosing the wrong one wastes time. Here is the difference in one table:

The one-table summary

  • Extract — copies chosen pages into one new PDF. Original untouched. Output: 1 file.
  • Split — divides a PDF into several new PDFs. Output: many files.
  • Delete — removes chosen pages, keeps the rest as one new PDF. Output: 1 file.

Real-world scenarios

“I need pages 5–8 of a 200-page contract to send to my lawyer.”

Extract. You want a single small file containing just those pages. Use Extract Pages and type 5-8.

“I scanned 40 invoices and each one needs to be filed separately.”

Split. You want 40 separate PDFs. Use Split PDF in "one file per page" mode — every result downloads automatically.

“This report has 12 pages of appendices I'm not allowed to share.”

Delete. You want the document to stay whole, minus those pages. Use Delete Pages and select the appendix range.

“I need to send 60 pages but the portal only accepts 10 MB.”

Neither extract, split nor delete directly — this is a compression job. That said, if you only truly need 10 of the 60 pages, extract first; a smaller page count usually gets you under the limit anyway.

The mental model that makes it stick

Think of a PDF as a binder:

  • Extract = photocopy a few sheets into a new binder.
  • Split = take the binder apart into several binders.
  • Delete = shred a few sheets and keep the binder.

Does any of this change the original file?

No — and that surprises people. All three operations produce new files; your original PDF stays exactly as it was on disk. So there is no risk in experimenting. The only thing to double-check is that you selected the right pages before downloading.

Quality: copied vs re-rendered

There is one more technical difference worth knowing. Some methods (browser print-to-PDF, some desktop apps) re-render pages — they redraw everything, which can soften scans and flatten form fields. Others, including PDFSnip, copy the original page objects byte-for-byte: text stays selectable, images keep full resolution, and the output looks identical to the source. When a document is legal, medical, or scanned, always prefer a tool that copies.
