How to Extract Pages from a PDF in Chrome

No software, no upload — Chrome's print dialog is a surprisingly capable page extractor.

If you have Google Chrome (or Edge, Brave, or any Chromium browser), you already have a basic PDF page extractor built in. It works by "printing" a page range to a new PDF file. It takes about 30 seconds and never uploads your document anywhere.

Step-by-step: extract pages with Chrome's print dialog

  1. Open the PDF in Chrome. Drag the PDF file into a blank tab, or right-click the file → Open With → Google Chrome.
  2. Open the print dialog. Press Ctrl+P (Windows) or Cmd+P (Mac).
  3. Set the destination. In the Destination dropdown, choose Save as PDF.
  4. Enter the page range. Under Pages, select Custom and type the pages you want, for example 3-7 or 1, 4, 9-12.
  5. Save. Click Save and choose where to store the new PDF. It contains only the pages you listed.

What Chrome's method is good at

  • It is free and requires nothing but the browser you already have.
  • Everything happens on your computer — the file is never uploaded.
  • It accepts custom ranges like 1, 4, 9-12 in one go.

The limitations you should know about

  • Form fields get flattened. Fillable PDFs (contracts, tax forms) lose their interactive fields after re-printing.
  • Pages are re-rendered, not copied. Chrome re-draws each page, which can soften scanned images and slightly change text appearance.
  • No visual selection. You need to know the page numbers in advance — there are no thumbnails to click.
  • Bookmarks and links do not carry over.

When to use a dedicated extractor instead

If you are working with scanned documents, fillable forms, or you simply don't know the page numbers yet, a proper extraction tool copies the original pages byte-for-byte instead of re-rendering them. Verdict

For a quick one-off — "grab pages 5 to 8 of this contract" — Chrome's print dialog is genuinely good. For anything involving scans, forms, or visual page picking, use a tool that copies pages instead of re-printing them.
